# Glossary

| Term | Means |
| --- | --- |
| Stream Deck | The installed Elgato application selected by the user. |
| Virtual keys | Virtual Stream Deck access enabled by this utility. |
| Pretty please | The action that checks compatibility and enables virtual keys. |
| Backup | The exact previous value of the activation preference and its restoration metadata. |
| Restore Last Change | Restore the latest preference change made by this utility. |
