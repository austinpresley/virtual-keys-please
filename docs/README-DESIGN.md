# GitHub landing page

The README is the landing page. The release, source and branded introduction
live together on GitHub; no separate hosting or hosted build is needed.

Use the app's paper cream #FAF5EB, plum #663D9E and ink #38214D, with the same
six lilac, peach, lime, butter, aqua and pink keys. Rounded system type is
rendered into the artwork so it looks like the Mac app on other platforms.

The memorable element is one short looping key-party banner. The rest is quiet:
a download button, three real steps and a small compatibility note. The banner
has light/dark and static Reduce Motion alternatives. Native app screenshots
sit in an optional preview. There are no feature-card grids or invented claims.

Review: cream and plum come directly from the existing app, rather than a new
web theme. The smiling key faces and six-color arrangement are the subject,
not decorative stock imagery. Copy uses the app's Pretty please action and
A little courtesy. A lot of keys. line.
