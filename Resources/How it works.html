Virtual keys, please.

A little Mac utility for enabling Virtual Stream Deck. No installer, account, terminal command or extra tool is needed.

Say please

  1. Open Virtual Keys Please directly from the disk image.
  2. Click Pretty please, or drop the Elgato Stream Deck app onto the window. Stream Deck may briefly restart.
  3. In Stream Deck's device menu, choose Add Virtual Device. Arrange your buttons, then enjoy the floating keys.

You can quit this utility and eject the disk image when you're finished.

What changes

The utility backs up one local activation preference, then extends the Virtual Stream Deck expiry to January 1, 2100. Your Stream Deck app, its signature, plugins and button profiles stay intact. No background service is installed.

Future versions

It recognizes the activation method, rather than requiring a particular version number. It has been verified with Stream Deck 7.6.0. A future release can work if it retains the same constant, key derivation and record format. A changed method requires a new utility build. An Elgato update, activation reset or newly connected physical device can replace the activation record; run this utility again if needed.

Put it back

Use Backups → Restore Last Change, or the File menu. Restore changes only the activation preference and refuses to overwrite a newer independent change. Backups stay in your user Library, under Application Support/Virtual Keys Please/Backups.

Macs

Universal Intel and Apple Silicon build, macOS 13 or later. Verified live on Apple Silicon with macOS 27. Older macOS and Intel hardware have not been tested live.
